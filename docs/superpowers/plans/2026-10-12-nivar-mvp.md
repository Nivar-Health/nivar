# Nivar MVP - Implementation Plan

Spec: `docs/superpowers/specs/2026-10-12-nivar-mvp-design.md` (the contract every task builds against).
Execution: subagent-driven, in waves, with integration and browser E2E by the lead after each wave.

## Wave 0 - Foundation (lead, done)

- pnpm workspace root, `docker-compose.yml` (Mongo on 27018), `.gitignore`.
- `apps/web`: Next.js 16 (App Router, TS, Tailwind v4, turbopack), shadcn/ui (base-nova style on Base UI) with core components, socket.io-client, leaflet, react-leaflet, lucide-react, date-fns.
- `apps/api`: package.json with express 5, mongoose 9, socket.io, jsonwebtoken, bcryptjs, zod 4, cors, helmet, morgan; supertest + eslint for dev.

## Wave 1 - parallel

### Task A: API (apps/api)
Files: `src/server.js`, `src/app.js`, `src/config.js`, `src/db.js`, `src/models/*`, `src/middleware/{auth,error,validate}.js`, `src/routes/{auth,me,catalog,bookings,admin,leads}.js`, `src/services/booking-status.js`, `src/realtime/index.js`, `src/seed/{index,data,ecg}.js`, `test/*.test.js`, `eslint.config.js`, `.env.example`.
Done when: `pnpm seed` populates the database per spec section 8; every endpoint in section 5 and every event in section 6 works; tests cover auth, the full booking lifecycle, transition guards, and role access; lint passes.

### Task B: Web foundation (apps/web)
Files: `src/app/globals.css` + `layout.tsx` (theme, fonts, Toaster), `src/lib/{api,types,auth,socket,format}.ts(x)`, `src/components/{brand/logo,status-badge,booking-stepper,app-shell,staff-shell,require-role}.tsx`, `src/app/login/page.tsx`, `src/app/staff/login/page.tsx`, placeholder role home pages.
Done when: customer OTP login and staff login work against the API, the role guard redirects, shells render on mobile and desktop, `build` and `lint` pass.

### Task C: Live components (apps/web)
Files: `src/lib/device-sim.ts`, `src/lib/heart-sound.ts`, `src/components/live/{ecg-monitor,ecg-strip,steth-monitor,live-map,video-call}.tsx`, plus a dev-only showcase page `src/app/dev/live/page.tsx`.
Done when: the showcase renders a streaming ECG, stethoscope waveform with audible heartbeat, moving map marker, and a two-tab video call works on localhost.

## Wave 2 - parallel (after Wave 1 merges)

- Task D: Landing page `/` (spec section 7, public).
- Task E: Patient app `/app/**` including booking wizard, tracking, consult, report.
- Task F: Nurse `/nurse/**` and Doctor `/doctor/**`.
- Task G: Admin `/admin/**`.

## Wave 3 - lead

- Integrate, run all four journeys in the browser side by side, fix every bug and visual defect found.
- `docs/DEMO.md` demo script and root `README.md`.
- Final: tests, lint, build all green; commit.
